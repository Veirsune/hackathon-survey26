# Provenance

This candidate copies the locally evaluated event-driven variant from `formal_event_driven_notes_off`. The local study disabled model calls externally; this submission enables the existing Kimi integrations without changing the tested scheduling policy.

`agent_core/vendor_notes_schedule.py` is unmodified from Team Argelander, commit `a98cb68324effbe11bc0d732ea519dafc4285edd`, under MIT (see `LICENSE.argelander`). Action arbitration and integration are ours.

Local no-model tests completed on L4/L2, announced-fault variants and an all-false-note counterexample. Those constructed tests do not establish performance on cloud cards. This branch is submitted for one after-party evaluation with Kimi.
