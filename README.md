# Survey Observer

A survey26 agent combining Kimi station-note interpretation, numerical scheduling, and observation-based terrain feedback. Supported statements for the same direction are reconciled conservatively instead of discarding the entire response.

Configure model credentials in platform settings. Kimi Coding Plan requests omit `temperature`; the manifest installs dependencies and runs the JSONL agent.

This experimental branch keeps model reasoning enabled. See [BENCHMARK.md](BENCHMARK.md) for local results and limitations.
