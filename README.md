# Survey Observer

A survey26 agent combining Kimi station-note interpretation, numerical scheduling, and observation-based terrain feedback. Fully zero-scoring exposures temporarily reduce priority around the failed pointing; the penalty expires after ten minutes.

Configure model credentials in platform settings. Kimi Coding Plan requests omit `temperature`; the manifest installs dependencies and runs the JSONL agent.

This experimental branch preserves bounded model reasoning and conservative claim reconciliation. See [BENCHMARK.md](BENCHMARK.md) for measured gains and regressions.
