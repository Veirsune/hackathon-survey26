# Survey Observer

A survey26 agent combining Kimi station-note interpretation, numerical scheduling, and observation-based terrain feedback. This experimental branch interprets station notes in the background while numerical observation continues.

Configure model credentials in platform settings. Kimi Coding Plan requests omit `temperature`; the manifest installs dependencies and runs the JSONL agent.

See [BENCHMARK.md](BENCHMARK.md) for results and timing tradeoffs.
