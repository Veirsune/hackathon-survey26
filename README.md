# Survey Observer

A survey26 agent with numerical observation scheduling and Kimi interpretation of station terrain notes. It validates quoted evidence and converts explicitly stated zenith angles into altitude limits.

Configure model credentials through the platform settings. Kimi Coding Plan calls omit `temperature`. The project manifest installs dependencies and runs the JSONL agent.

See [BENCHMARK.md](BENCHMARK.md) for local results and limitations. This experimental branch does not select the platform final version.
